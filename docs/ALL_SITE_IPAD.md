# Apple iPad: all 13 sites

This is a **small proof-of-access and proof-of-extraction** test, not a full crawler.
Each store gets one starting page, optionally up to two category pages, and
up to three discovered product URLs. Public, previously observed category
pages are used for Trendyol, n11, Vatan and Teknosa; the remaining sites use
their homepages to find Apple/iPad category links automatically.

Possible results include seed unavailable, no product links discovered,
products not verified, and product name + price found. A missing link is
**not** a claim that a store lacks Apple products.

No CAPTCHA bypass, no login, no invented product URLs, no guaranteed live access.
The workflow runs on merge and publishes JSON and a summary; inspect its
actual run before declaring any store operational.
